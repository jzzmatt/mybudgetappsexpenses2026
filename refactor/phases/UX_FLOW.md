## Add Expense
Choose:
1. Manual Entry
2. Import Payment PDF

### Manual
Normal expense form. Project is inherited from current workspace. Currency is display-only.

### Import Payment PDF
Upload PDF
→ Analyze
→ AI Draft
→ Review
→ Confirm
→ Expense created with original PDF retained.

### Review screen
Show extracted values with clear AI/extracted indicators.
User can edit:
- Date
- Description
- Category
- Vendor/Person
- Expense Budget
- Paid Amount
- Payment Method
- Priority
- Status
- Notes

Project and currency are inherited and not editable.

Show original PDF preview/open action.

Show extraction confidence/uncertainty only where useful; do not pretend confidence is proof.

### Expense details
Show:
- all expense fields
- payment reference
- original Payment Proof
- view/download proof action
- Expense Paid %
- Project Budget Impact %
