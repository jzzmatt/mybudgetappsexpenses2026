# Target UX Flow

Global navigation:
- My Projects
- Categories
- Vendors
- Settings

Do not make a global Expenses page the primary navigation.

Flow:
Login → My Projects → Create/Open Project → Project Overview → Expenses → Reports → AI Report.

Create Project:
- Name
- Budget
- Currency (default AOA)

Project Overview:
- Number of Expenses
- Project Budget
- Total Expense Budget
- Total Paid
- Total Expense Remaining
- Available Budget
- Budget usage
- Category/month charts
- Recent Expenses
- Add Expense

Expense form:
- Date
- Description
- Category
- Vendor
- Project context (display only)
- Currency (display only, inherited)
- Expense Budget
- Paid Amount
- Priority
- Status
- Notes

Expense list:
Date, Category, Vendor, Currency, Expense Budget, Paid, Remaining, Expense Paid %, Project Budget Impact %, Status, Actions.
