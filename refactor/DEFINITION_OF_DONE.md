# Definition of Done

A phase is complete only when:
- Its requirements are implemented.
- No future phase is implemented.
- Unrelated functionality remains intact.
- Security/RLS is preserved.
- Financial formulas match PRODUCT_MODEL.md.
- Relevant tests pass.
- TypeScript passes.
- Lint passes or unrelated warnings are documented.
- Database changes are validated.
- Responsive/accessibility impact is checked where applicable.
- Cursor reports changed files and verification results.
- Cursor stops for approval.
